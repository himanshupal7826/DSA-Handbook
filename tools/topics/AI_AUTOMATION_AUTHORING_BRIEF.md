## Accuracy sheet (Part 1)
- **Claude (anthropic SDK):** `anthropic.Anthropic()` reads `ANTHROPIC_API_KEY`. `client.messages.create(model=..., max_tokens=..., system=..., messages=[...])`; iterate `response.content` and check `block.type == "text"`. Default model `claude-opus-5-5`; current family also `claude-sonnet-5-5`, `claude-haiku-5-5` (never add date suffixes). Structured output: `client.messages.parse(..., output_format=PydanticModel)` → `response.parsed_output`, or `output_config={"format": {"type": "json_schema", "schema": {...}}}` (old top-level `output_format` on `create` is deprecated). Strict tools: `"strict": True` + `additionalProperties: false`. **Forced `tool_choice` `any`/`tool` returns 400 on Opus 5.5 / Sonnet 5.5** — use `auto` + prompt + strict. **Sampling params (`temperature`/`top_p`/`top_k`) are rejected on current Claude models** (and on every model under API version 2026-10-21) — depth is controlled with `output_config={"effort": "low"|"medium"|"high"|"xhigh"|"max"}`; thinking is adaptive (`thinking={"type": "adaptive"}`), Opus 5.5 default effort `medium`. No assistant prefill on current models. SDK auto-retries 429/5xx (`max_retries` default 2). Errors: `anthropic.RateLimitError`, `APIStatusError`, `APIConnectionError`. Token counting: `client.messages.count_tokens(...)` (not tiktoken). Prices/M tokens: Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50. Prompt caching: `cache_control={"type": "ephemeral"}`; verify via `usage.cache_read_input_tokens`.
- **OpenAI SDK:** Responses API is the primary surface (`client.responses.create(model=, instructions=, input=)` → `response.output_text`; `client.responses.parse(..., text_format=Model)` → `output_parsed`). Chat Completions (`client.chat.completions.create`) remains and is the lingua franca of OpenAI-compatible servers (Groq, Ollama, OpenRouter, LiteLLM proxy, vLLM). Embeddings: `client.embeddings.create(model="text-embedding-3-small", input=[...])`.
- **Gemini:** use `google-genai` (`from google import genai`; `genai.Client()` reads `GEMINI_API_KEY`/`GOOGLE_API_KEY`); `client.models.generate_content(model=, contents=, config=types.GenerateContentConfig(...))` → `.text`. The old `google-generativeai` package is deprecated.
- **Groq:** `groq.Groq()` reads `GROQ_API_KEY`; Chat-Completions-shaped API; very low latency on open-weight models.
- **Ollama:** REST on `http://localhost:11434`; native `/api/chat`, OpenAI-compatible `/v1`; Python `ollama.chat(model=, messages=)`; `ollama pull <model>`; embeddings via `ollama.embed`.
- **LiteLLM:** `litellm.completion(model="provider/model", messages=...)` returns OpenAI-shaped responses; `Router` for fallbacks/load-balancing; proxy server for teams (virtual keys, budgets).
- **OpenRouter:** OpenAI-compatible base URL `https://openrouter.ai/api/v1`, `OPENROUTER_API_KEY`, model ids `vendor/model`.
- Don't state prices or limits you aren't sure of — say "check the pricing page" and show how to compute.
